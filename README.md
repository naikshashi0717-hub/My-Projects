# My Web Projects

A collection of responsive, beginner-friendly web applications built with **HTML5**, **CSS3**, and **JavaScript (ES6+)**. 

---

##  Projects Included

### 1.  Personal Expense Tracker (`personalexpensetarcker/`)
A web interface for managing personal finances and tracking daily expenses.
* **Features:** Login interface, responsive layout, dynamic script execution for expense tracking.
* **Files:** `indexloginpage.html`, `indexloginpage.css`, `interface.html`, `script.js`

### 2.  To-Do List Application (`todo/`)
A simple and efficient productivity tool to add, complete, and organize daily tasks.
* **Features:** Interactive UI, real-time task management using JavaScript DOM manipulation.
* **Files:** `todo.html`, `todo.css`, `todo.js`

### 3.  Weather App (`weather/`)
A clean dashboard to check weather updates and forecasts.
* **Features:** Styled layout for weather data presentation, interactive script handling.
* **Files:** `weather.html`, `weather.css`, `weather.js`
